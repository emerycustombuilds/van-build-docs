# Van Build Docs — Emery Custom Builds

Technical documentation for van conversions, powered by [Mintlify](https://mintlify.com).

## What's Here

Reference guides for van build electrical systems, plumbing, build process, budgeting, and tools. Written by [Emery Custom Builds](https://emerycustombuilds.com) — a custom van conversion shop in Costa Mesa, CA.

## Development

This repo is connected to Mintlify and auto-deploys on push. To preview locally:

```bash
npx mintlify dev
```
